# 우리집 식단

요일·끼니별 인원과 난이도를 정하면 1주 또는 4주 식단을 짜 주고, 주 단위 장보기 리스트를 만들어 주는 폰용 웹앱입니다. 서버가 없고, 설정과 식단은 쓰는 기기의 브라우저에만 저장됩니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 미리 보기
```

## 레시피 수정

레시피는 `src/recipes/breakfast.json`, `lunch.json`, `dinner.json` 에 들어 있습니다. 새 레시피를 넣거나 고치려면 Claude에게 말해서 파일을 고치고 다시 배포합니다. 형식 검사는 `npm test` 가 합니다.

- 재료 분량은 **1인분 기준**이고, 인원수에 비례해 늘어납니다.
- 소금, 후추, 식용유, 설탕, 간장, 참기름, 깨, 고춧가루, 다진 마늘, 물, 올리브유는 집에 항상 있다고 보고 재료 목록에 넣지 않습니다.
- 같은 재료는 항상 같은 이름과 카테고리를 씁니다(테스트가 확인).

## 배포 (무료 정적 호스팅)

`npm run build` 가 만드는 `dist/` 폴더를 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 됩니다. `vite.config.ts` 의 `base: './'` 때문에 하위 경로에서도 동작합니다. 호스팅 계정은 사용자가 정해야 하므로 아직 배포하지 않았습니다.
